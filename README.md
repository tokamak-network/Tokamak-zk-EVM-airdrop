# TON AIRDROP ON TONIGMA

Make a valid private-state transfer on Tonigma, submit the transaction hash, and earn `25 TON` per valid submission.

Use the airdrop page: <https://airdrop.tonigma.network>

## How To Participate

1. Ask your AI agents to install the latest version of `@tokamak-private-dapps/private-state-cli`.
2. Ask your AI agents to join `the-great-first-channel`.
3. Ask your AI agents to make one private-state transfer notes transaction on Tonigma.
4. Ask your AI agents for the transaction hash.
5. Submit the transaction hash on the airdrop page.

Never share your Ethereum wallet private key or any secrets with others including us.

## Prerequisites

- Channel entry fee: `4 TON` (partially refundable conditionally)
- Your EOA private key, kept private and never disclosed
- Node RPC URL (recommended: Ankr's free API)

## Winner Criteria

- The submitted transaction hash must be from a real private-state transfer notes transaction made in Tonigma.
- The Ethereum wallet address that sent the transaction must have been joined to Tonigma when the transaction happened.
- The reward is sent to the Tonigma channel address registered to that Ethereum wallet address at that time.
- A Tonigma channel address can receive only one reward.
- A transaction hash can be used only once.

## Status Labels

- `Pending`: the submission is waiting for verification or payout.
- `Transferred`: the reward transfer succeeded.
- `Failed`: the submission cannot receive a reward. Hover the label on the airdrop page to see every recorded failure reason.

## About Tonigma

Tonigma is the public name for `the-great-first-channel`, one of the Tokamak Private App Channels and a dedicated channel for the private-state DApp.

The private-state DApp turns TON into proof-backed confidential notes inside Tonigma, enabling channel-local transfers without exposing note ownership or transfer meaning in public contract state.

To learn more, read [docs](https://github.com/tokamak-network/Tokamak-zk-EVM-contracts/blob/main/docs/index.md).
