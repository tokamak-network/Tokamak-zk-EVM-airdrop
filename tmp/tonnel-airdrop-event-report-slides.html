Tonnel Airdrop Event Report June 4, 2026

Executive Summary

The event ended with a clear market signal.

225 Successful reward transfers shown in the exported histograms.
50.7% Share of successful transfers attributed to Indonesia.
25 TON Base reward rule implemented for each valid submission.

The next event should be treated as a distribution campaign first: stronger promotion is the main lever for broader reward distribution.

Executive Summary 2

Event Outcome

A lean, auditable public airdrop.

What users did

  • Joined Tonnel, the public name for the-great-first-channel.
  • Completed a real private-state transfer-notes transaction.
  • Submitted only the transaction hash through the public site.

What the system verified

  • The transaction existed and succeeded on Ethereum.
  • It called the Tonnel channel manager.
  • It represented a valid private-state transfer-notes action.
  • The payout address was resolved from channel registration data.
Event Outcome 3

Execution Method

Campaign flow from user action to payout.

1

Public page explained the reward, safety rules, and participation guide.

2

User made a private-state transfer in Tonnel using the CLI.

3

API accepted a transaction hash and rejected malformed values.

4

Local worker verified eligibility through RPC and artifacts.

5

Valid submissions received private-state reward payouts.

Public payout execution was intentionally disabled; the operator worker handled verification and transfer from the controlled local runtime.

Reward Distribution 6

Positive Findings

Three signals matter for the next campaign.

Indonesia is priority one

The region produced the majority of successful transfers and should be treated as a primary go-to-market target.

Telegram is a core channel

Crypto-native discovery and coordination are stronger in Telegram than X for some trader communities.

UX improved during the event

The app, worker operations, CLI guidance, and educational materials all became easier to operate and explain.

Positive Findings 7

Limitations

The issue was reach, not the reward rule.

Promotion was insufficient. The correction is stronger promotion before and during the next event.

Observed effect

A limited number of highly active participants captured a significant share of the reward pool.

Planned response

Increase the number of real participants reached through Indonesian communities, Telegram, Reddit, and conferences.
